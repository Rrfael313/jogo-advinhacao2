
# 🎮 Jogo de Adivinhação

## Descrição

Este é um jogo desenvolvido utilizando HTML, CSS e JavaScript.

O objetivo é descobrir um número secreto gerado
aleatoriamente entre 1 e 100.

O jogador possui 10 tentativas para acertar o número.

Durante o jogo, recebe dicas informando se o número
secreto é maior ou menor que o palpite.

## Funcionalidades

- Geração de número aleatório.
- Limite de 10 tentativas.
- Validação de números inteiros entre 1 e 100.
- Dicas durante as tentativas.
- Mensagem de vitória ou derrota.
- Botão para reiniciar o jogo.
- Layout adaptável para celulares.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Baixe ou copie os arquivos do projeto.
2. Abra a pasta no Visual Studio Code.
3. Abra o arquivo index.html.
4. Utilize a extensão Live Server para executar.
5. O jogo será aberto no navegador.
